# 배포 복구

| 상황 | 행동 |
|---|---|
| `login` | CLI login 후 재시도. MCP 재연결로 CLI 로그인을 대체하지 않는다. |
| `request_access` | 계정 배포 권한을 확인한다. 반복 로그인하지 않는다. |
| `update_cli` | 지원되는 CLI 버전을 사용한다. |
| `choose_new_slug` | 사용할 수 없는 앱 이름이다. 새 slug를 정하고 변경된 경로에 맞춰 다시 빌드한다. |
| `check_status` | 표시된 ID로 status. ID를 모르면 원래 프로젝트에서 status를 실행해 연결 기록을 사용한다. 기록도 없으면 list로 앱을 식별해 담당자에게 확인한다. |
| `use_input_file` | Secret 원문을 비공개 파일로 전달한다. 터미널 입력은 거절된다. |
| `check_configuration` | 오류 코드에 맞춰 빌드·명령·연결을 확인한다. 불명확하면 중단·보고한다. |

- `issued/running`: 같은 파일·설정으로 deploy를 다시 실행하면 같은 배포를 이어 간다. CLI가 같은 요청 ID로 허가증을 갱신하며 최초 업로드 대기 마감(1시간)은 늘어나지 않는다.
- `unknown`: 임의 취소·새 앱 생성·반복 배포하지 않는다. 상태 조회 후 담당자에게 확인한다.
- `completed`: 공개 기능을 확인한다. 다음 변경은 새 배포로 진행한다.
- `failed/expired`: 원인을 해결하고 새 배포를 실행한다.
- 허가증 응답 유실: 같은 내용은 같은 요청 ID로 재시도한다. 이전 Secret 값 등을 복원할 수 없어 내용이 달라졌다면 새 요청을 보내고, 서버가 반환한 진행 중 배포 ID로 상태를 확인한다. 이전 작업을 자동 취소하거나 덮어쓰지는 않는다.
- 로컬 기록은 `.bigvalue/production.json`이다. 토큰·고객 파일은 없지만 기존 앱 연결과 중단 복구에 필요하므로 임의 삭제하지 않는다.
- 서버·설정·목록 multipart 합계 10MiB, 정적 파일당 25MiB, 총 2,000개 한도를 확인한다. 정적 파일 본문은 Cloudflare로 직접 전송한다.
- 로그인 자격은 사용자 홈에 환경별 저장된다. 30일 동안 갱신하지 않아 만료되거나 연결이 폐기되면 다시 로그인한다. 로그아웃은 서버 연결 폐기까지 확인한다.
