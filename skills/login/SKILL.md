# 로그인

데이터 연결(MCP)의 로그인 상태를 판정하고, 로그인 전이면 이 세션 안에서 브라우저 인증을 시작한다.
이미 로그인돼 있으면 아무것도 바꾸지 않고 그렇다고 보고한다.

이 스킬은 Claude Code·Claude Desktop 세션용이다. Codex는 `setup` 스킬의 Codex 경로를 따른다.

## 순서

1. **판정** — 이 플러그인의 데이터 도구를 가볍게 한 번 호출한다(예: 지역 요약을 `limit: 1`로).
   - 성공하면: "이미 연결돼 있습니다"라고 보고하고 끝낸다. 로그인을 다시 시키지 않는다.
   - 인증 오류(401·authentication 계열)면: 2로 간다.
   - 참고: `/mcp` 목록의 `✔ Connected`는 로그인 완료의 증거가 아니다. 도구 목록은 로그인 없이도 열려 있다. 판정은 반드시 실호출로 한다.
2. **로그인 시작** — 이 서버가 노출하는 `authenticate` 도구를 호출한다. 클로드가 미인증 OAuth 서버에 붙여 주는 세션 안 로그인 장치다. 인증 URL이 나오면 사용자에게 보여 주고, 브라우저에서 구글 계정 로그인과 동의를 마치게 안내한다.
3. **완료** — 사용자가 브라우저 로그인을 마쳤다고 하면, **사이에 다른 도구를 하나도 호출하지 말고 곧바로** `complete_authentication`을 호출한다. 중간에 다른 호출이 끼거나 연결이 끊기면 진행 중이던 인증 상태가 사라지는 알려진 문제가 있다. 그래서 2와 3 사이에는 상태 조회도 하지 않는다.
4. **증명** — 1의 판정 호출을 다시 실행해 성공을 확인하고 결과를 보고한다.

## 이 흐름이 실패하면

한 번 더 시도해 볼 가치는 있다(2~3을 처음부터). 그래도 안 되면 아래를 안내하고 멈춘다 — 둘 다 사용자가 직접 한다.

- `/mcp`를 실행해 `bigvalue-realestate`를 선택하면 같은 브라우저 로그인이 뜬다.
- 외부 대화형 터미널에서 `claude mcp login plugin:bigvalue-realestate:bigvalue-realestate`를 실행한다. 이 셸 명령은 스킬이 대신 실행하지 않는다 — 브라우저 콜백이 대화형 터미널에서만 안정적으로 끝난다. 로그인 뒤에는 새 세션에서 확인한다.

"연결할 수 없는 계정입니다" 화면이 뜨면 로그인 계정이 허용 목록에 없는 것이다. 온보딩 담당자에게 계정 허용을 요청하게 안내한다.

## 경계

- 인가 코드·토큰 값을 출력하거나 기록하지 않는다. 사용자에게 보여 주는 것은 인증 URL까지다.
- 설정 파일·자격증명 파일을 직접 편집하지 않는다.
- 로그인 여부와 무관하게 데이터 조회 요청 자체는 이 스킬이 아니라 해당 데이터 스킬·도구가 처리한다.
